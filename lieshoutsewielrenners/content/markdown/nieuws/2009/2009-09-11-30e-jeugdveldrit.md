# 30e JEUGDVELDRIT

Als voorbereiding op het Nederlands Kampioenschap veldrijden voor de jeugd op zaterdag 23 januari 2010 organiseert de suportersclub "De Lieshoutse Wielrenners" op zondag 6 december 2009 de 30ste jeugdveldrit van Lieshout. Eerste start 12.00 uur. Parcours "'t Hof".
