# Italiaanse winst in Bavaria veldrit van Lieshout

De Italiaan Marco Bianco is winnaar geworden van de Bavaria veldrit van Lieshout 2008. De overige winnaars zijn:

|  |  |
| --- | --- |
| Amateurs: | Edwin Raats |
| Nieuwelingen: | Danny van Poppel |
| Junioren: | Gert-Jan Bosman |
| Elite/Beloften: | Marco Bianco |
| Masters: | Frank Groenendaal |
